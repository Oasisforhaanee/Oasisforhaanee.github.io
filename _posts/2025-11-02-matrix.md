The matrix is one of the foundational objects of university mathematics, underpinning linear algebra and much of multivariable calculus. It is often introduced purely as a computational device, but the object itself carries a rich geometric meaning. This post examines what a matrix actually represents.

## Matrix

A matrix is, literally, an array of numbers arranged in rows and columns. The meaning encoded in that arrangement, however, is considerable.

First, a matrix can represent a vector. For example, the vector $(1,1)$ can be written as the following column vector. (Throughout this post, column vectors and coordinate notation are used interchangeably; they denote the same vector.)

$$P=\begin{bmatrix}1\\1\end{bmatrix}$$

## Basis Vectors

The familiar plane described by an $x$-axis and a $y$-axis is two-dimensional space. The most elementary basis vectors for this space are given below. Basis vectors are the vectors used to describe a space:

$$i=\begin{bmatrix}1\\0\end{bmatrix}\ \ \ \ j=\begin{bmatrix}0\\1\end{bmatrix}$$

Every vector in the plane can be written in terms of these column vectors—for instance, $(3,2)=3i+2j$. However, other pairs of vectors can also describe every vector in the plane:

$$a=\begin{bmatrix}2\\0\end{bmatrix}\ \ \ \ b=\begin{bmatrix}1\\2\end{bmatrix}\ \ \ \ \ \begin{bmatrix}3\\2\end{bmatrix}=a+b$$

The vectors $a$ and $b$ above reproduce $(3,2)$ even though they are not $(1,0)$ and $(0,1)$.

The most conventional basis vectors, $i$ and $j$, are called the **standard basis vectors**. Two-dimensional space can be described using vectors other than the standard basis, but the standard basis is the canonical choice.

## Matrices as Space Transformations

Now consider the following situation. Suppose the familiar $xy$-plane is stretched to twice its size in the $x$-direction. The entire space is stretched horizontally: a point with $x$-coordinate 4 moves to 8, a point with $x$-coordinate 2 moves to 4, and $y$-coordinates are unchanged. Any vector that existed in the original space is stretched in the $x$-direction as well. When a transformation is applied, every vector in the space moves together with the space.

A matrix expresses exactly this kind of spatial transformation numerically. The matrix $A$ below represents the transformation just described:

$$A=\begin{bmatrix}2&0\\0&1\end{bmatrix}$$

The meaning of $A$ is as follows:

- It maps the standard basis vector $i=(1,0)$ to $(2,0)$, and $j=(0,1)$ to $(0,1)$.

If a vector in the original space was $3i+2j$, then after the transformation—since $i$ has been doubled—the same expression $3i+2j$ now denotes a vector whose $x$-coordinate is twice as large as before. This process is expressed by matrix multiplication.

Let $X$ be an arbitrary vector:

$$X=\begin{bmatrix}2\\1\end{bmatrix}$$

The matrix product $AX$ then gives the position of $X$ after it has been moved by the transformation $A$.

To compute a matrix product, multiply the entries in each row of the first matrix with the corresponding entries in each column of the second matrix and sum the results. Multiplying row 1 of $A$ with column 1 of $X$ and summing gives the entry in row 1, column 1 of $AX$:

$$AX=\begin{bmatrix}2&0\\0&1\end{bmatrix}\begin{bmatrix}2\\1\end{bmatrix}=\begin{bmatrix}2\times 2+0\times 1\\0\times 2+1\times 1\end{bmatrix}=\begin{bmatrix}4\\1\end{bmatrix}$$

The resulting vector $(4,1)$ is the image of $X=(2,1)$ under the transformation $A$.

Where are such transformations used in practice? One example closely related to the discussion above is font transformation. When a typeface is slanted, the underlying space is transformed and that transformation is applied to each glyph. Applying the transformation that doubles only the $x$-coordinate to an ordinary glyph produces a letter that is stretched horizontally.

## Matrices and Equations

Systems of equations can also be expressed using matrices.

Consider, for example, the system

$$2x+y=3$$

$$x-y=3$$

In matrix form, this system becomes

$$\begin{bmatrix}2&1\\1&1\end{bmatrix}\begin{bmatrix}x\\y\end{bmatrix}=\begin{bmatrix}3\\3\end{bmatrix}$$

$$A=\begin{bmatrix}2&1\\1&1\end{bmatrix}\ \ \ X=\ \begin{bmatrix}x\\y\end{bmatrix}\ \ \ \ B=\begin{bmatrix}3\\3\end{bmatrix}$$

We established that a matrix such as $A$ represents a transformation of space. The equation can therefore be read as follows: find the vector $X$ that is carried to the vector $B$ when the transformation $A$ is applied.

Now consider a system in three unknowns:

$$2x+3y-z=5$$

$$x-2y+4z=4$$

$$3x+y-2z=2$$

This system can be written as the matrix equation

$$\begin{bmatrix}2&3&-1\\1&-2&4\\3&1&-2\end{bmatrix}\begin{bmatrix}x\\y\\z\end{bmatrix}=\begin{bmatrix}2x+3y-z\\x-2y+4z\\3x+y-2z\end{bmatrix}\ =\begin{bmatrix}5\\4\\2\end{bmatrix}$$

$$A=\begin{bmatrix}2&3&-1\\1&-2&4\\3&1&-2\end{bmatrix}\ \ \ X=\begin{bmatrix}x\\y\\z\end{bmatrix}\ \ B=\begin{bmatrix}5\\4\\2\end{bmatrix}$$

The vector $X$ that is mapped onto $B$ by the transformation $A$ is precisely the solution of the system. The animation below shows the blue vector $X$ undergoing the linear transformation and finally coinciding with $B$. The blue vector before the transformation (at $t=0$) is the solution, which evaluates to

$$\begin{bmatrix}x\\y\\z\end{bmatrix}=\begin{bmatrix}\frac{8}{7}\\\frac{48}{35}\\\frac{7}{5}\end{bmatrix}$$

In practice, systems of equations are solved far more conveniently by elimination. Nevertheless, knowing that a system can be interpreted geometrically as a transformation makes linear algebra considerably more meaningful.
