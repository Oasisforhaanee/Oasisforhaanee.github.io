Anyone who has studied university mathematics has probably heard of matrices. The matrix is a very important concept, so much so that it can be seen as a cornerstone of mathematics, including linear algebra and calculus.

I had learned the concept of matrices in high school, but at that time matrices had been removed from the curriculum. Also, when I first learned matrices at university, I only studied how to compute with them, without ever trying to deeply understand what they actually mean.

So in this post, based on what I've studied again, let's look at what meaning a matrix really has.

## Matrix

A matrix is, literally, just numbers placed in rows and columns. But the meaning contained inside this matrix is very rich.

First, a matrix can express a vector. For example, the vector $(1,1)$ can be expressed as the following column vector (the column vector and the vector expressed as coordinates will probably be used interchangeably in this post, but please think of them all as the same vector):

$$P=\begin{bmatrix}1\\1\end{bmatrix}$$

## Basis Vectors

The space we usually think of, expressed with an x-axis and y-axis, is 2D space. The most basic basis vectors here are as follows. Basis vectors are vectors used to express space:

$$i=\begin{bmatrix}1\\0\end{bmatrix}\ \ \ \ j=\begin{bmatrix}0\\1\end{bmatrix}$$

We can express every vector in 2D space with these column vectors. Like $(3,2)=3i+2j$. But we can also express every vector in 2D space with other vectors:

$$a=\begin{bmatrix}2\\0\end{bmatrix}\ \ \ \ b=\begin{bmatrix}1\\2\end{bmatrix}\ \ \ \ \ \begin{bmatrix}3\\2\end{bmatrix}=a+b$$

The vectors a and b above were able to express the earlier $(3,2)$ even though they aren't $(1,0)$ and $(0,1)$.

Basis vectors like i and j, which are the most standard, are called **standard basis vectors**. You can express 2D space with vectors that aren't standard basis vectors, but the most standard vectors are the standard basis vectors.

## Matrices as Space Transformations

Now let's think about this case. What happens if we stretch the familiar xy-plane to twice its size in the x-axis direction? The whole space will stretch in the x-axis direction. Where the x-coordinate was 4 it will become 8, and where it was 2 it will become 4. The y-coordinates won't change at all. If there was a vector in the space before stretching, that vector will also have stretched in the x-axis direction. When a transformation happens, all the vectors in the space move along with the space.

A matrix expresses this kind of space transformation with numbers. The matrix A below expresses the transformation above:

$$A=\begin{bmatrix}2&0\\0&1\end{bmatrix}$$

The meaning that matrix A has is as follows:

- It transforms the standard basis vector $i=(1,0)$ to $(2,0)$, and $j=(0,1)$ to $(0,1)$.

If the vector on the space before the transformation was $3i+2j$, then after the transformation, since i has been doubled, even if it's still expressed as $3i+2j$, it represents a form where the x-coordinate has increased by a factor of 2 compared to before. This process can be expressed using matrix multiplication.

If an arbitrary vector X is:

$$X=\begin{bmatrix}2\\1\end{bmatrix}$$

then the meaning of the matrix product AX is the position of X after moving it according to matrix A's transformation.

The way to compute the matrix product is to multiply the numbers in each row of the front matrix with the numbers in each column of the back matrix sequentially and add them up. Multiplying the numbers in row 1 of matrix A with the numbers in column 1 of matrix X and adding them gives the entry in row 1, column 1 of AX:

$$AX=\begin{bmatrix}2&0\\0&1\end{bmatrix}\begin{bmatrix}2\\1\end{bmatrix}=\begin{bmatrix}2\times 2+0\times 1\\0\times 2+1\times 1\end{bmatrix}=\begin{bmatrix}4\\1\end{bmatrix}$$

The $(4,1)$ vector that comes out this way is the vector after transforming the X$(2,1)$ vector through matrix A.

## Matrices and Equations

The equations we know can also be expressed using matrices.

For example, suppose we have the system of equations:

$$2x+y=3$$

$$x-y=3$$

If we express this system using matrices:

$$\begin{bmatrix}2&1\\1&1\end{bmatrix}\begin{bmatrix}x\\y\end{bmatrix}=\begin{bmatrix}3\\3\end{bmatrix}$$

$$A=\begin{bmatrix}2&1\\1&1\end{bmatrix}\ \ \ X=\ \begin{bmatrix}x\\y\end{bmatrix}\ \ \ \ B=\begin{bmatrix}3\\3\end{bmatrix}$$

We said that a matrix like A is a matrix that represents a space transformation. In other words, this equation can be seen as finding the vector X that becomes the vector B after the space transformation A has been applied.

Let's also look at a case with a system of equations with three unknowns:

$$2x+3y-z=5$$

$$x-2y+4z=4$$

$$3x+y-2z=2$$

Suppose we have the system of equations above. This can be expressed as the following matrix:

$$\begin{bmatrix}2&3&-1\\1&-2&4\\3&1&-2\end{bmatrix}\begin{bmatrix}x\\y\\z\end{bmatrix}=\begin{bmatrix}2x+3y-z\\x-2y+4z\\3x+y-2z\end{bmatrix}\ =\begin{bmatrix}5\\4\\2\end{bmatrix}$$

$$A=\begin{bmatrix}2&3&-1\\1&-2&4\\3&1&-2\end{bmatrix}\ \ \ X=\begin{bmatrix}x\\y\\z\end{bmatrix}\ \ B=\begin{bmatrix}5\\4\\2\end{bmatrix}$$

The X vector before the transformation that points to the B vector after the space transformation A has been applied is exactly the solution of this equation. The video below shows the process of the blue vector X going through a linear transformation and finally pointing to the B vector. The blue vector before the linear transformation is the blue vector at t=0, and if you actually compute it, it comes out as follows:

$$\begin{bmatrix}x\\y\\z\end{bmatrix}=\begin{bmatrix}\frac{8}{7}\\\frac{48}{35}\\\frac{7}{5}\end{bmatrix}$$
